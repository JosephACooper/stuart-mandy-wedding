# Stuart & Mandy

A responsive wedding invitation website with a paper-textured, 3D envelope opening sequence.

## Development

```bash
pnpm install
pnpm dev
```

The site runs at `http://localhost:5173/`.

## Animation lab

Open `http://localhost:5173/?animationLab=1` to scrub and tune the opening sequence. Add `&clean=1` for the presentation-only version.

## Production

```bash
pnpm lint
pnpm build
```
